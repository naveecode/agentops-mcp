AgentOps MCP

A tool-calling LangGraph agent served by FastAPI with a Redis cache. The same tools are exposed as an MCP server for Cursor and Claude Desktop. Source on GitHub.

This is a static demo page. The live backend is not hosted; run it locally with docker compose up.

Chat UI

Architecture

flowchart LR
  UI[Next.js chat UI] --> API[FastAPI /ask]
  API --> C[(Redis cache)]
  API --> AG[LangGraph ReAct agent]
  AG --> T[Tools: search_docs, calculator]
  MCP[MCP server stdio] --> T
  API --> K[Docker / kind K8s]

Quickstart

git clone https://github.com/naveecode/agentops-mcp && cd agentops-mcp
docker compose up        # API on :8000, Redis
python -m app.mcp_server # MCP for Cursor / Claude
